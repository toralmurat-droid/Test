# Pixel Town Brawl

An online multiplayer pixel-art action RPG in the browser: heroes fight monsters, bosses and each other across two
acts, level up to 50, learn skill trees, collect gear and runes, and run quests and dungeons.

- **Client:** Phaser 3 + TypeScript (Vite). Isometric by default; art is mostly generated by code.
- **Server:** Colyseus 0.16 (Node.js, `@colyseus/schema` 3). The server is authoritative: movement, combat, loot,
  quests and saves are all decided there.
- **Shared:** game rules and data used by both sides (`shared/`).

Working on the code? Read [CLAUDE.md](CLAUDE.md) (technical rules) and [CONTRIBUTING.md](CONTRIBUTING.md) (how
we work). Numbers in this file are examples; the source of truth is the `shared/` file named next to each feature.

## Run locally

```bash
npm install
npm run dev
```

Desktop browsers only (mouse and keyboard); phones and tablets are not supported.

Open http://localhost:5173 in two browser tabs to see the multiplayer. The game server runs on port 2567.

`npm run live` instead of `npm run dev` keeps a local game on the latest merged version: it checks GitHub every
minute, fast-forwards when the branch has new commits (running `npm install` if dependencies changed) and restarts
the game. It skips an update rather than overwrite local commits or edits.

Other scripts: `npm test` (unit tests), `npm run build` (typecheck + bundles), `npm run bench` (server load bench),
`npm run art` (regenerate sprite sheets into `client/public/assets`).

## Put it online

See [DEPLOY.md](DEPLOY.md): Railway + the `Dockerfile`, with a volume at `/app/data` for player saves and
auto-deploy on every merge.

```bash
npm run build
npm start
```

This runs one Node server (default `PORT=2567`) that serves the built client and the game over WebSockets, with a
`/health` check for the host.

## The game

### Classes (`shared/classes.ts`)
Only the classes in `ACTIVE_CLASSES` can be played. Archived classes keep their code, art and saves.

| Class | Status | Style | Skill branches (`shared/skills.ts`) |
|---|---|---|---|
| Wizard | active | Ranged spells | Fire, Frost, Thunder |
| Vampire | active | Blade and blood magic, lifesteal, Bat and Wolf forms | Blood, Night, Fang |
| Summoner | active | "Lord of the Void": permanent elemental golems, wisps, Void weapons, black holes (`shared/summons.ts`) | Golems, Void, Conjuration |
| Songweaver | active | Oakvale minstrel with a lute: party songs, keys (modes) unlocked by the tree, chords from note progressions, sound that bounces and builds resonance (`shared/songs.ts`) | Hymnal, Folk, Discord |
| Knight, Ninja, Archer, Barbarian | archived | Sword, rapid strikes, bow, axe | — |

### Progression
- **Levels** up to 50 (`MAX_LEVEL`, `shared/classes.ts`). Act 1 tops out around level 30; the rest is earned in
  Act 2 (`ACT2_LEVEL`, `shared/constants.ts`).
- **Stats** (`shared/powers.ts`): you place points yourself in the hero panel (1 per level, 3 at levels 3, 5, 8 and
  10). Stamina, Strength, Magic and Dexterity.
- **Skill trees** (`shared/skills.ts`, `shared/talents.ts`): one point per level, 3 branches per class, each a small
  tree of attacks, upgrades, passives, auras and an ultimate. Skills go on the skill bar (`shared/slots.ts`).
- **Resets** of stats and skills are free at low level, then cost gold (`shared/upkeep.ts`).
- **Gear** (`shared/gear.ts`, `shared/weapons.ts`): drops with rarity and bonuses and level requirements.
  **Runes** (`shared/runes.ts`) go into gear sockets for passive effects, come out whole,
  and four identical runes fuse into a higher rank.
- **Shops, trade and parties:** `shared/shops.ts`, `shared/trade.ts`, `shared/party.ts`.

### Combat
- **Basic attack and combos** (`combo` in `shared/classes.ts`), a **dodge roll** (`DODGE`), and 8-way aim.
- **Poise** (`shared/combat.ts`): hits drain a hidden bar; below half you attack slower, at zero you are dizzy.
  A broken-poise monster can be **executed**.
- **Elemental reactions** on monsters (`shared/elements.ts`) and **champion monsters** with affixes
  (`shared/champions.ts`, `server/champions.ts`).
- **PvP:** heroes can fight each other anywhere except the **Market Square**, Kel Ashar's market and Cairnwatch's square (safe zones). Newcomer protection is off
  (`PVP_PROTECT_LEVEL = 0` in `shared/combat.ts`).
- **Night Raiders** (`shared/raiders.ts`): named level-50 riders who roam both acts at night.

### World and content
- **Act 1 — Oakvale** (`shared/map.ts`): a starting village in a valley of farms, woods, ruins, a marsh, a quarry,
  a keep and a coast, with monster levels growing with distance from the village (`zoneLevels` in
  `shared/spawns.ts`).
- **Act 2 — the Sunscar** (`shared/desert.ts`, `shared/act2.ts`): a desert reached through the old waygate south of
  Oakvale once Act 1's last bosses are down, with the city of Kel Ashar and a final boss, Ishael the Sunwright, at the Sun Furnace.
- **Act 3 — the Grey Barrow Moors** (`shared/moors.ts`): the Ossuary Host's barrow country (levels 20-35), reached
  through the Moorgate in the forest north of the Hollow Throne once a hero reaches level 20. The Cairn Wardens hold the outpost of Cairnwatch (portal stone, bounty board,
  shops); Warden-Captain Edra Vane's chain climbs through the barrows to the Barrow-King, who wakes at night.
- **Act 4 — the Red Badlands** (`shared/badlands.ts`): the Redfang clan's homeland of red mesas, canyons
  and dry riverbeds (levels 25-40), reached through the Red Pass at Oakvale's west edge once a hero reaches level 25.
  The Rustwater Post holds out with a portal stone, a bounty board and shops; Marshal Hesk Varro's chain climbs
  through Talon Fort and Gallows Canyon to Old Rourke in Fangrock Keep. The badlands are a land of the clan war, joined to
  Oakvale by the Red Pass, with Fangrock as the Redfang seat.
- **Dungeons** (`shared/dungeon.ts`): the Mawdeep, the Lantern Crypt and the Undercity.
- **Quests** (`shared/quests.ts`): zone quest arcs in both acts, quest bosses (some only at night).
- **Bounty boards** (`shared/bounty.ts`): pick a hunt for your level, paid when the last kill lands.
- **Monsters** (`MOBS` in `shared/constants.ts`) live in spawn zones (`SPAWN_ZONES` in `shared/spawns.ts`) and
  respawn while a zone is below its cap.
- **Day and night:** a 30-minute cycle shared by all players (`shared/daynight.ts`).
- **Player ideas** (`shared/ideas.ts`, press **I**): players suggest one improvement a day and vote; each hour the
  best idea wins. Log in `data/ideas.json`, readable at `/ideas.json`. Winners are built by hand.

The map is generated deterministically in code, so the server and every client build the same world.
`npx tsx tools/map-metrics.ts` prints walkability, reachability and detour numbers.

### Controls
Two keyboard layouts, picked in the game menu (**Esc**) (`client/src/keymode.ts`):

- **Classic:** WASD or arrows to walk, Space to attack, skills on 1–0, F dodge, Q health potion, V mana potion,
  R ranged weapon, E use, C character, G bag, T skill tree.
- **Spell keys:** the mouse walks, spells on Q W E R T and 1–5, X dodge, D / F potions, V ranged weapon, G use,
  H character, C bag, K skill tree.

In both: Enter chat, M world map, J quest log, P party, I ideas, N news (patch notes), Alt+Enter full screen, hold Alt over a monster for its details.
Chat emotes: /wave /cheer /laugh /sit /sleep.

### Viewing aids
- **Isometric view** is the default; `?iso=0` gives the old top-down view (`client/src/iso.ts`). Only drawing
  changes; the server and map stay top-down.
- `?time=day|dusk|night` forces a time of day, `?zoom=1.5` zooms out, `?look=tx,ty` looks at a tile.
- **Map viewer:** with `npm run dev` running, open http://localhost:5173/map.html for the whole map with area,
  collision and grid overlays (no server needed). It hot-reloads when `shared/map.ts` changes.

## Accounts and saves

Players log in with a name and password; a new name creates the account. An optional email allows password reset by
emailed code (`server/mailer.ts`). Each account keeps one saved hero per class.

Saves are written by the server on leave, every 30 seconds and on shutdown: to `data/saves.json` (change with
`SAVE_FILE=...`), or to Postgres when `DATABASE_URL` is set (`server/accounts.ts`). World state (the Tide meter) goes to
`world.json` next to the save file (`WORLD_FILE=...`), or to a `world` Postgres table (`server/worldStore.ts`). Passwords are stored hashed
(scrypt). Back up the save file; it is not in git. During a restart, players are handed over through
`data/handoff.json` and come back where they stood.

Testing: any player can type `/max` in chat to jump to the max level with every skill at max rank and all stat
points placed.

## Layout

```
shared/   game rules and data: classes, skills + skillEngine, monsters, items, gear, runes, map, quests, dungeons
server/   index.ts (HTTP + Colyseus), TownRoom.ts (state, tick, combat, chat), accounts, saves, champions, mobGrid
client/   index.html, map.html (map viewer), src/ (TownScene.ts, art, effects, UI panels), patchnotes/, public/assets/
tests/    node:test unit and room tests (tests/helpers/room.ts runs a real room)
tools/    balance sims (duel, pve), art generator, perf bench, smoke and e2e scripts, map metrics
docs/     progress logs for big features, art previews, music prompts
```
